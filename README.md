# ravshanbek.dev

Personal website — React 18 + TypeScript + Vite 4 (runs on Node 16+).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
npm run preview  # serve the build locally
```

All copy, links and the accent colour live in `src/content.ts`. Replace the `[BRACKETED]` placeholders there.

Deploy `dist/` to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages).
